Agent skills for building [Guren](https://guren.dev) applications with Claude Code, Cursor, Codex, GitHub Copilot, OpenCode and other coding agents.

**This repository is generated.** Its contents are rendered from
[gurenjs/guren](https://github.com/gurenjs/guren) and published on each Guren

the next publish. Send changes to `gurenjs/guren` instead.

The first published version is on its way. Until then, install the harness
inside a Guren app with `bunx guren agent:init`.
